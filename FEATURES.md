# Features

- Learns NPC health from observed combat damage and healing.
- Saves learned health by realm, creature type, level and classification.
- Shows current NPC health on the default target frame.
- Adds current and maximum health to mouseover tooltips, with estimates labelled.
- Provides target-frame or tooltip-only display modes.
- Includes an in-game settings panel with saved preferences.
- Shows live cache statistics, realm information and current target details in settings.
- Provides an in-game communications test with an inline result.
- Shares learned health with guild and party/raid members using the addon, enabled by default with an option to disable it.
- Includes `/mobhp` commands for settings, diagnostics and cache management.
- Runs as a standalone Lua addon with no additional addon dependencies.
- Includes source code under the MIT license.

Supports World of Warcraft Classic 1.14.2 (Interface 11402). See
[README.md](README.md) for installation, usage and estimation limits.
